# ocr-proofread

OCR 校对 / 图像 ROI 标注工具（PySide6 + QGraphicsView）。

**用途与边界**：逐张查看扫描件或拍摄的文档图像，在图上框出文字区域（ROI），对选中的或
全部的 ROI 跑 OCR，把识别结果挂在对应的 ROI 上一起存盘，选中标注时旁边就有个小框显示
这段文本，并在图上直接改掉识别错的字。每个 ROI 在本张图上还有一个**顺序号**（默认就是
创建顺序，也可以在排序模式里按点击顺序重排）。当前版本覆盖"浏览 + 框选 + 标注存取 +
排序 + OCR 识别 + 文本编辑"：打开图像、缩放平移、上下张切换、左键拖出矩形并调整、
每张图的标注与识别结果随图切换自动保存与恢复，识别文本双击即可就地修改（横排 / 竖排
两种排版都能显示）。批量替换、逐字校对、导出等更完整的校对工作流不在范围内。

## 环境准备

本项目使用 [uv](https://docs.astral.sh/uv/) 管理 Python 环境，解释器为 Python 3.14。

```bash
export UV_CACHE_DIR="$PWD/.uv-cache"   # 见下方沙箱说明
uv sync                                 # 创建 .venv 并安装依赖
```

> **沙箱说明**：当前环境下 `$HOME` 中的 uv 缓存目录只读，因此本项目的 uv 缓存被放在项目内的
> `.uv-cache/`（已加入 `.gitignore`）。执行任何 `uv` 命令前都需要先设置上面的 `UV_CACHE_DIR`。

只安装 `pyside6-essentials`，不含 Addons、WebEngine 等模块；OCR 用
[manga-ocr](https://github.com/kha-white/manga-ocr)（会一并装上 PyTorch，体积不小，
CPU 也够用）。原因与取舍见 [docs/architecture.md](docs/architecture.md#环境与依赖)。

> **首次识别会下载模型**：manga-ocr 的权重（约 400 MB）在第一次识别时从 HuggingFace
> 拉取并缓存，之后离线可用；加载期间状态栏会显示"正在识别"，请耐心等待。

## 运行

```bash
uv run ocr-proofread                       # 空窗口启动
uv run ocr-proofread ~/data/pages          # 直接打开文件夹
uv run ocr-proofread a.png b.jpg           # 直接打开若干图像
uv run python -m ocr_proofread <路径...>    # 等价写法
```

也可以用鼠标把文件夹或图像文件拖进窗口。命令行传入的文件夹按自然顺序展开，文件按给定顺序打开。

## 功能

- **打开文件夹**：扫描文件夹内的图像（png/jpg/bmp/gif/webp/tif/…），按**自然顺序**排序
  （`img2.png` 排在 `img10.png` 前面），忽略隐藏文件与非图像文件；仅扫描顶层，不递归。
- **导入图像**：多选文件，按选择顺序浏览。
- **浏览**：上一张 / 下一张、第一张 / 最后一张，到边界时对应动作自动禁用。
- **缩放**：以鼠标为锚点的滚轮缩放，快捷键放大/缩小，适应窗口、实际大小（100%）；
  缩放范围限制在 2%–4000%。窗口尺寸变化时，若仍处于"适应窗口"状态会自动重新适配。
  适应窗口沿用 Qt `fitInView` 语义：小图会被放大填满窗口，`Ctrl+1` 可回到 100%。
- **平移**：按住空格后用左键拖动（抓手模式，此时不会新建矩形），或中键拖动画布；
  Shift+滚轮水平滚动、Alt+滚轮垂直滚动。
- **框选标注**：左键在图像上拖动即可拉出一个矩形；距离太小的拖动（误点击）会自动丢弃。
  点选图元后可拖动本体移动，拖动八个手柄缩放；移动与缩放都被夹在图像范围内，也不会被拖成一条线。
- **每图标注**：标注按图像分开保存。切上一张 / 下一张时自动保存当前图、恢复目标图的标注，
  状态栏显示当前图的标注数量；`Ctrl+S` 可随时手动保存。
- **ROI 顺序**：每个标注在本张图上有一个从 1 开始的顺序号，**初始就是框的创建顺序**
  （不是按坐标排的），新建的框排在最后；删掉几个之后序号会自动补成连续的 1..N。
  顺序号随标注一起写进边车文件里的 `index` 字段，右侧结果面板第一列的 `#` 显示的就是它，
  面板行序、存盘顺序、`Ctrl+Shift+R` 识别全部的顺序都按这个顺序来。
- **ROI 排序模式**：`Ctrl+Shift+S` 进入 / 退出（「标注 → ROI 排序模式」同一个动作），
  只作用于当前这张图。进入后每个框的左上角出现角标：还没点到的是灰色 `?`，点到过的
  显示它的新序号。**按鼠标点击顺序，从 1 开始依次编号**（第一个点的是 1，第二个是 2…）；
  没点到的框保持原有相对次序接在后面，所以点一半退出也不会丢框。每点一次就立刻落盘。
  这个模式下左键只用来编号：不拉新矩形、不选中、不拖动图元，双击也不会进文本编辑；
  中键 / 空格拖动仍然可以平移画布，滚轮照样缩放。点错了可以 `Esc` 退出、重新进入从头排
  （已经点过的框再点一次不会改动，状态栏会说明它排在几位）。切图会自动退出这个模式。
- **标注存储**：写在图像旁边的 `<图像文件名>.roi.json`（JSON，坐标单位是图像像素、原点在
  左上角）。没有标注的图不会生成文件；标注被清空后文件会自动删除。边车文件不是图像，
  不会被扫描进浏览列表。
- **OCR 识别**：`Ctrl+R` 识别**选中的**标注，`Ctrl+Shift+R` 识别**当前图的全部**标注。
  识别在后台线程里逐个跑，状态栏显示进度，界面不会卡死；识别完的结果挂在对应的 ROI 上，
  切图或 `Ctrl+S` 时随标注一起写进同一个边车文件。识别到一半切图会先停下，已经识别出来的
  部分照样保存。
- **识别模型**：「OCR → 识别模型」里选，目前只有 `manga-ocr`（日文漫画 / 印刷体），
  选择会记进设置、下次启动继续用。引擎在第一次识别时才加载模型，识别失败（没装依赖、
  模型下载失败、图块为空等）会在状态栏和弹窗里给出具体原因。
- **识别结果面板**：右侧列出当前图每个 ROI 的顺序号、位置、尺寸与识别文本；点某一行会
  选中并定位到图像上对应的框，反之在图上选中标注也会高亮对应行。「OCR → 识别结果面板」
  可显示 / 隐藏。
- **编辑识别文本**：双击图像上的标注，或双击结果面板里的文本行，就地修改这个 ROI 的
  `text`；编辑中 `Ctrl+Enter` 或点到别处采纳、`Esc` 放弃。改完立刻写进边车文件，不必
  等切图；正在编辑时切图或 `Ctrl+S` 也会先把已经敲进去的字收下。没识别过的标注也能
  这样手写文本。
- **标注旁的文本框**：选中某个标注时，它旁边会出现一个小框，显示这个框的识别文本，
  不用扭头看右侧面板。长文本自动换行、超出部分用省略号收尾，没识别过的显示
  「（未识别）」；字号与框的大小按屏幕像素算，画布缩放到 2% 或 4000% 都一样清楚。
  点一下框会选中它所属的标注，双击框同样是编辑文本。
- **文本框的位置与大小**：横排的框贴在标注的**上方或下方**，竖排的贴在**左方或右方**；
  位置挑余量大的一侧（能整框放下的一侧优先），缩放、平移、拖动标注之后都会重新判断。
  排得下时框与标注对齐：横排的框宽 = 标注在屏幕上的宽，竖排的框高 = 标注的高；
  标注本身放不下字、或这个尺寸超出视口时，退回按文字自然大小排。
- **文本框字号**：光标放在框上滚滚轮就能调（此时滚轮不再缩放画布）。默认字号就是能
  调到的最小字号；再调大就装不下整段文字时会被拒绝，并在状态栏说明原因。字号记进
  设置，下次启动继续用。
- **文本排版方向**：「视图 → 文本框排版方向」在两种排版之间切换，选择记进设置、下次
  启动继续用（只影响显示，不写进标注文件）：
  - **横排 / 横書き**：左→右排布，上→下换行（默认），框贴标注的上下
  - **竖排 / 縦書き**：上→下排布，右→左换列（日漫竖排文字用这个），框贴标注的左右
- **状态栏**：`[当前/总数] 文件名 宽×高 所在目录` + 当前图的标注数（含已识别数）+
  当前缩放百分比。
- **持久化**：记住窗口大小、上次打开的目录、上次用的 OCR 模型、文本框排版方向与字号。
- **容错**：单张图读取失败时只在状态栏提示并停留在原图，不中断浏览；EXIF 方向会自动校正。

## 标注存到哪

识别结果直接写进原来的标注边车文件，一个 ROI 一条记录，`text` 就是识别文本；没识别过的
标注不写这个字段。手改过的文本同理：改完立刻落盘，清空文本则该字段又消失。

`index` 是这个 ROI 在本张图上的顺序号（从 1 开始），没排过号的老记录不写这个字段。
文件版本升到 3，旧版本文件照常读入：v1 只有几何，v2 多了 `text`；没有 `index` 的记录
按文件里的先后重新编号（当年的写盘顺序就是坐标顺序），照样能用。

```json
{
  "version": 3,
  "image": "page_02.png",
  "annotations": [
    { "x": 150.0, "y": 720.0, "w": 940.0, "h": 70.0, "index": 1 },
    { "x": 150.0, "y": 630.0, "w": 940.0, "h": 70.0, "text": "認識されたテキスト", "index": 2 }
  ]
}
```

## 快捷键

| 按键                               | 功能              |
| ---------------------------------- | ----------------- |
| `Ctrl+Shift+O`                     | 打开文件夹        |
| `Ctrl+O`                           | 导入图像文件      |
| `←` / `A` / `PageUp` / `Backspace` | 上一张            |
| `→` / `D` / `PageDown`             | 下一张            |
| `Home` / `End`                     | 第一张 / 最后一张 |
| 滚轮 或 `Ctrl+滚轮`                | 以鼠标为中心缩放  |
| `Ctrl+=` / `Ctrl+-`                | 放大 / 缩小       |
| `Ctrl+0` 或 `F`                    | 适应窗口          |
| `Ctrl+1`                           | 实际大小（100%）  |
| 空格按住 + 左键拖动                | 平移画布（抓手，不新建矩形） |
| 左键在图像上拖动                   | 拉出一个矩形标注  |
| 左键拖动图元本体 / 手柄            | 移动 / 缩放标注   |
| 排序模式中左键点图元               | 把它排到下一个顺序号（1、2、3…） |
| 双击图元 / 双击结果面板文本行      | 编辑该 ROI 的识别文本 |
| `Ctrl+Enter` / `Esc`（编辑中）     | 采纳 / 放弃文本编辑 |
| 光标在标注旁的文本框上 + 滚轮      | 调整文本框字号（默认即最小） |
| `Delete`                           | 删除选中的标注    |
| `Ctrl+S`                           | 保存当前图的标注  |
| `Ctrl+Shift+S`                     | 进入 / 退出 ROI 排序模式（按点击顺序编号 1、2、3…） |
| `Ctrl+R`                           | OCR 识别选中的标注 |
| `Ctrl+Shift+R`                     | OCR 识别当前图的全部标注 |
| `Esc`                              | 放弃正在拉的矩形 / 取消选中 / 退出排序模式 |
| `Ctrl+Q`                           | 退出              |
| 中键拖动                           | 平移画布          |
| `Shift+滚轮` / `Alt+滚轮`          | 水平 / 垂直滚动   |

程序内「帮助 → 快捷键」会弹出同一份列表。
